Project Overview

Understanding network topology and open port exposures is fundamental to defensive cybersecurity. While heavyweight enterprise scanners provide extensive feature sets, they often introduce complex dependencies and steep learning curves for rapid local network audits.

JARVX is designed as a focused, lightweight command-line utility. Built using raw Python socket programming, it validates IPv4 CIDR blocks, initiates threaded connection sweeps across common and extended port ranges, measures connection latency, and outputs structured risk assessments.

Implemented & Planned Features

01 IMPLEMENTED

CIDR Notation & IP Validation

Calculates host ranges dynamically from subnet masks and validates target inputs against invalid loopbacks and reserved spaces.

02 IMPLEMENTED

Dual Scanning Modes (Quick / Deep)

Offers targeted scans across the top 100 high-risk service ports or deep sweeps across all 65,535 TCP socket endpoints.

03 IMPLEMENTED

Multi-Threaded Socket Engine

Concurrent thread dispatch pool achieving sub-5-second sweeps across standard /24 subnets.

04 PLANNED ROADMAP

Automated Service Banner Grabbing

Passive protocol handshake interrogation to capture web server, SSH, and database version banners.
