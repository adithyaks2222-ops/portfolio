Project Overview

Modern operating systems continuously execute hundreds of background processes, maintain dynamic socket connections, and register startup services. Without dedicated visibility tooling, diagnosing suspicious behavioral anomalies or unintended network exposure requires navigating fragmented system utilities.

CAPX (Cyber Analysis & Protection eXplorer) is engineered as a lightweight Windows analysis tool. It extracts process telemetry, inspects open network sockets, maps binary execution paths, and evaluates risk indicators to deliver immediate visibility into local machine health.

Implemented & Planned Features

01 IMPLEMENTED

Live Process Telemetry

Enumerate running PIDs, memory utilization, parent-child process relationships, and executable integrity signatures.

02 IMPLEMENTED

Network Socket Inspection

Inspect listening TCP/UDP endpoints, detect anomalous ephemeral port activity, and resolve foreign IP addresses.

03 IMPLEMENTED

Startup Behaviour Tracking

Inspect persistent registry Run keys, scheduled startup tasks, and non-standard binary launch arguments.

04 PLANNED ROADMAP

Automated Heuristic Quarantine

One-click process suspension and safe sandbox isolation for unknown binaries matching risk thresholds.
