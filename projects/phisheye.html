Project Overview

Phishing campaigns increasingly utilize automated domain generation algorithms, lookalike characters (typosquatting/homograph attacks), and newly registered SSL certificates to bypass traditional static blacklists.

PhishEye evaluates visited web pages directly on the client machine before users submit sensitive credentials. By combining structural URL heuristics, Shannon entropy scoring, and DOM form-target verification, PhishEye provides clear, actionable safety ratings without routing user browsing history through external third-party servers.

Implemented & Planned Features

01 IMPLEMENTED

Domain Entropy & URL Heuristics

Calculates character randomness, subdomain nesting depth, and homoglyph substitution patterns in the active browser tab.

02 IMPLEMENTED

3-Tier Verdict Classification

Categorizes visited destinations into SAFE, WARNING, or DANGER indicators with explicit risk breakdowns.

03 IMPLEMENTED

Password Form Interception

Detects password input elements targeting mismatched external domains or unencrypted transport endpoints.

04 PLANNED ROADMAP

Local Offline Heuristic Cache

Lightweight Bloom filter integration to evaluate verified domain reputations entirely offline.
