Project Overview

Most automated code linting tools generate dry, robotic warning logs that developers quickly ignore. Furthermore, cloud-based AI code assistants require sending proprietary codebases to remote servers, raising critical data privacy concerns for sensitive engineering projects.

CodeBurner combines local LLM inference with memorable feedback. By connecting directly to a local Ollama instance running Llama 3, CodeBurner delivers line-by-line critiques, OWASP security alerts, and constructive refactoring advice without a single byte of code leaving the local workstation.

Implemented & Planned Features

01 IMPLEMENTED

Multiple Feedback Personalities

Switch between "Brutal Mentor (Roast Mode)", "Pragmatic Senior Dev", and "Security Auditor" review tones.

02 IMPLEMENTED

100% Private Offline Inference

Direct HTTP connection to local Ollama endpoints (e.g. `llama3:8b-instruct`), ensuring complete code confidentiality.

03 IMPLEMENTED

In-Editor Gutter Annotations

Visual gutter markers highlight flagged anti-patterns and provide one-click suggested refactorings.

04 PLANNED ROADMAP

Git Diff Pre-Commit Hook

Automated pre-commit inspection that reviews staged git diffs before allowing code to be pushed to remotes.
