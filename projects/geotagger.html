Project Overview

Managing large photo archives for collegiate organizations, club initiatives, and field activities often demands verifying that specific events occurred at documented physical venues and timestamps. Sorting through unstructured image directories without geospatial metadata is tedious and error-prone.

GeoTagger reads standard EXIF metadata embedded directly in JPEG/HEIC binary files, extracts GPS latitude, longitude, and altitude tags, cross-verifies timestamp accuracy, and renders visual pin markers on Google Maps to generate structured venue reports.

Implemented & Planned Features

01 IMPLEMENTED

Client-Side EXIF Parsing

Binary parser reading exchangeable image file format headers directly in the browser without uploading media to external servers.

02 IMPLEMENTED

Interactive Map Pin Cluster

Synchronizes parsed coordinates with Google Maps API, grouping photos by location clusters and spatial accuracy radii.

03 IMPLEMENTED

GPS Metadata Inspector

Displays exact degrees-minutes-seconds coordinates, altitude above sea level, and camera hardware capture parameters.

04 PLANNED ROADMAP

Batch Report PDF Export

Automated export generating branded institutional event reports with thumbnail proofs and verified map stamps.
